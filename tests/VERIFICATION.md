- CI 与 Release workflow 已增加回归测试步骤；云端执行结果须单独核验，本地通过不能替代云端结果。

```powershell
MSBuild.exe tests/FFKeyLock.UI.Tests.vcxproj /p:Configuration=Release /p:Platform=x64 /m
tests/artifacts/x64/FFKeyLock.UI.Tests.exe tests/artifacts

```
