# v0.6.1 实机发布验收

以下项目尚待人工执行，自动回归通过不能代替这些结果。使用独立 `--config` 或解压后的便携配置；先退出日常实例，不要强制结束用户进程。

记录 Windows 版本、显示器缩放、键盘型号、游戏路径、游戏/反作弊版本，以及实际通过或失败的步骤。

- [ ] 应用防误触预设 → 放行 F2 → 保存 → 退出重启，F2 仍放行。
- [ ] 游戏前台锁定；聊天时锁键保持；Alt+Tab 撤销游戏专属保护；返回游戏恢复。
- [ ] 长按已屏蔽和已放行的键时切窗/暂停/换配置；松开后无卡键或孤立输入。分别测试 PrtSc、Scroll Lock、Pause / Ctrl+Pause。
- [ ] Ctrl+Alt+Backspace 紧急解除；切换游戏仍暂停；明确恢复后才继续保护。End/Home 替代组合也可用。
- [ ] 只开启锁键不切换输入法；关闭单个游戏或总保护可撤销相应保护。
- [ ] 同名但不同路径的两个程序分别应用各自配置。
- [ ] 未保存草稿切换游戏/关闭程序时，可保存、放弃或取消；主题和通知刷新保留草稿。
- [ ] 深浅主题、系统高对比度、100%/125%/150%/200% 缩放及跨屏移动；Tab、下拉选择、滚动和窄窗口布局正常。
- [ ] 安装版从 0.6.0 升级到 0.6.1，游戏库、语言、全局设置保留；静默升级也不覆盖配置。
- [ ] 便携 ZIP 首次运行在解压目录保存配置；更新时保留已有 portable.ini；不改安装版配置。
- [ ] ARM64 产物在 ARM64 Windows 上启动并完成关键输入验证。

安装与升级验收应在测试账户或虚拟机执行，避免修改日常安装和注册表。
