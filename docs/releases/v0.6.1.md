# FFKeyLock v0.6.1

## 中文

本次更新改善原生界面的主题一致性，并完善安装升级和便携包行为。

- 修复“额外按键”等下拉列表在拖动滑块、长按箭头及翻页时出现白色原生滚动条的问题，保留键盘、滚轮和选项选择行为。
- 游戏库与配置面板统一圆角、细边框和背景；滑块悬停、拖动时更容易辨认，按钮和输入框圆角保持一致。
- “测试配置”入口移至编辑器上方；紧急解除提示完整显示 `Ctrl + Alt + Backspace`。
- 安装版升级保留已有配置和语言；ZIP 默认携带空游戏库的 `portable.ini`，配置保存在解压目录。
- 发布流程校验 tag、源码、程序和安装包版本，并检查便携包内容。

### 下载与升级

选择与 Windows 架构相符的 `x64`、`x86` 或 `arm64` 安装包/ZIP。普通 64 位 Intel/AMD 电脑选择 `x64`。

- 安装版：退出旧版后运行安装包，已有 `%APPDATA%\FFKeyLock\config.ini` 保留。
- 便携版：退出旧版后更新程序文件，**保留自己的 `portable.ini`，不要被 ZIP 中的空白模板覆盖**。
- 从此前使用 AppData 配置的免安装版迁移时，可先导出游戏库，再在新便携版导入；全局设置需单独确认。

### 验证范围

本地 x64 / Win32 Release 构建通过，各通过 153 项功能回归和 331 项可见 UI 检查；11 项版本校验、隔离安装语言保留测试、ZIP 内容及便携启动/保存验证通过。

这些结果不代表实体键盘、真实游戏/反作弊、完整安装升级、高对比度和跨屏 DPI 均已实机验收；ARM64 未在本地构建或运行验证。云端构建结果见 [Release workflow](https://github.com/brealinxx/FFKeyLock/actions/workflows/release.yml)。

## English

This update improves native UI theme consistency and installation/portable-package behavior.

- Fix white native scrollbars appearing while dragging, holding arrows or paging through long dropdowns. Keyboard navigation, wheel scrolling and item selection remain available.
- Unify panel backgrounds, rounded corners and subtle borders; make scrollbar hover/drag states clearer and align button/field corners.
- Move the local key test near the top of the editor and spell out `Ctrl + Alt + Backspace` in the emergency hint.
- Preserve existing settings and language during installer upgrades. ZIP packages now include an empty-library `portable.ini` and save settings beside the executable.
- Validate release tags, source/artifact versions and portable-package contents before publishing.

### Download and upgrade

Choose the installer or ZIP matching your Windows architecture: `x64`, `x86` or `arm64`. Most 64-bit Intel/AMD PCs use `x64`.

- Installer: exit the old version and run setup. Existing `%APPDATA%\FFKeyLock\config.ini` is preserved.
- Portable: exit the old version and replace program files. **Keep your own `portable.ini`; do not overwrite it with the empty template from the ZIP.**
- Moving from an older ZIP that used AppData: export the game library first, then import it into the new portable copy. Check global settings separately.

### Verification scope

Local x64 / Win32 Release builds passed, with 153 regression checks and 331 visible UI checks per architecture. Version validation (11 checks), isolated installer-language preservation, ZIP contents and portable startup/save checks also passed.

Physical keyboards, real games/anti-cheat, full installation upgrades, high contrast and cross-monitor DPI still need manual acceptance. ARM64 was not built or run locally. See the [Release workflow](https://github.com/brealinxx/FFKeyLock/actions/workflows/release.yml) for cloud build results.
